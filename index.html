Tetapan
Cara sambung dalam 3 fasa
  1. Google Sheet: isi PIN (min 6 aksara, campur huruf & nombor) di tab Dashboard sel C13.
  2. Google Sheet: Extensions → Apps Script → Deploy → New deployment → Web app. Pilih Execute as: Me dan Who has access: Anyone → Deploy → benarkan akses → salin Web app URL.
  3. Vercel: klik butang Deploy dalam panduan, tampal URL tadi dalam kotak APPS_SCRIPT_URL → Deploy.
  4. Buka link Vercel anda → masukkan PIN → siap! Pasang di skrin utama telefon.

Rujuk PDF Cara Sambung Dashboard untuk panduan bergambar.
Pasang di skrin utama

iPhone / iPad (Safari): tekan butang Share ⬆️ → Add to Home Screen → Add.

Android (Chrome): tekan ⋮ (kanan atas) → Add to Home screen / Install app.

Laptop (Chrome / Edge): klik ikon pasang ⊕ di bar alamat, atau bookmark sahaja.
